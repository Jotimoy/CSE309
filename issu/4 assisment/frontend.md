# Frontend Task

## Goal
Add user login and registration pages to support user authentication and account management.

## Details
- Design responsive login and registration forms using the existing React + TypeScript frontend.
- Include form validation for required fields, email format, password strength, and matching passwords.
- Connect the forms to backend API endpoints for user signup and login.
- Display success and error messages clearly to the user.
- Add navigation links between login, registration, and any protected pages.
- Ensure frontend handles authenticated user state and redirects unauthenticated users to login.

## Tasks
- [ ] Create `LoginPage` component.
- [ ] Create `RegisterPage` component.
- [ ] Add form validation and error display.
- [ ] Add API service methods for login and register.
- [ ] Add protected route handling and redirect logic.
