# Backend Task

## Goal
Add authentication and authorization flow to support secure user access and protected resources.

## Details
- Implement user registration and login endpoints in the FastAPI backend.
- Use secure password hashing for stored credentials.
- Issue JSON Web Tokens (JWT) or session tokens after successful login.
- Protect backend routes with authentication middleware.
- Add role-based or permission-based access checks if needed.

## Tasks
- [ ] Create user model and authentication schema.
- [ ] Add registration endpoint.
- [ ] Add login endpoint.
- [ ] Implement token generation and validation.
- [ ] Secure protected API routes with authentication checks.
