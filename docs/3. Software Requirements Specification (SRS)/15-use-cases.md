# Use Cases

## Use Case 1: Process Incoming Shipment
- **Actor**: Warehouse Staff
- **Description**: Staff uses the system's OCR feature to scan packing slips and automatically register new inventory into the system.

## Use Case 2: Monitor Warehouse Health
- **Actor**: Warehouse Manager
- **Description**: Manager views the dashboard to see low-stock warnings, current warehouse capacity, and recent activities.

## Use Case 3: Generate Analytics Report
- **Actor**: Business Owner
- **Description**: Owner logs in and exports a monthly summary of inventory turnover rates and missing items.
