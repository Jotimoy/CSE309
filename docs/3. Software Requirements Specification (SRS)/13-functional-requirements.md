# Functional Requirements

- **FR1**: The system must allow users to log in with a username and password, supporting role-based access control (Admin, Manager, Staff).
- **FR2**: The system must integrate an OCR module to extract alphanumeric data from uploaded images or live camera feeds.
- **FR3**: The system must maintain a centralized database of all inventory items, allowing CRUD (Create, Read, Update, Delete) operations.
- **FR4**: The dashboard must refresh data in real-time or near real-time (e.g., via WebSockets or frequent polling).
- **FR5**: The system must support generating PDF and Excel reports for inventory levels and transaction histories.
- **FR6**: The system must trigger alerts when stock falls below predefined thresholds.
