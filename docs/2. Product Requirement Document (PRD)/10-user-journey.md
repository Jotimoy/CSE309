# User Journey

## Scenario: Logging new inventory via OCR

1. **Authentication**: The warehouse staff member logs into the system via their mobile device or tablet.
2. **Navigation**: User selects "Receive Stock" from the main dashboard.
3. **Image Capture**: User takes a picture of the supplier invoice or shipping label using the device camera.
4. **AI Processing**: The system uses Computer Vision and OCR to extract item names, quantities, and serial numbers.
5. **Verification**: User quickly reviews the extracted text on the screen.
6. **Confirmation**: User taps "Confirm", and the inventory is updated in the database instantly.
7. **Notification**: The warehouse manager's dashboard updates in real-time to reflect the new stock levels.
