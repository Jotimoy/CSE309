# User Stories

1. **As a** Warehouse Manager, **I want to** view a real-time dashboard of current stock levels **so that** I can make informed reordering decisions.

2. **As a** Warehouse Staff member, **I want to** scan text labels using OCR **so that** I do not have to manually type long serial numbers and product names.

3. **As a** Business Owner, **I want to** generate automated weekly reports **so that** I can track operational efficiency without requesting manual reports from managers.

4. **As a** Warehouse Manager, **I want to** receive low-stock alerts **so that** I can prevent stockouts.
